# Спаси меня

Маленькая история-игра для Алины: ночная поляна, квест от Люми, платформер, бой с Сомнением, клетка и тёплый финал. В финале Женя говорит спасибо.

## Играть

https://kokaomefedron.github.io/spasi-menya/

Игра сделана в первую очередь для телефона в вертикальном положении: сцена занимает верх экрана, диалоги и управление — нижнюю часть. На компьютере всё тоже работает.

## Управление

- `←` `→` или `A` `D` — идти
- `↑`, `W` или `Space` — прыгать
- `Space`, клик или касание — листать диалоги
- На телефоне — большие экранные кнопки внизу

## Персонализация

Имя героини в финале задаётся в самом верху `js/core.js`:

```js
const HER_NAME = 'Алина';
```

Имя Жени и финальную подпись можно поменять в `index.html` и в `CAGE_LINES` в `js/story.js`.

## Технологии

Чистый HTML, CSS и JavaScript. Графика рисуется на Canvas 2D, музыка и звуки генерируются через WebAudio. Без внешних картинок, шрифтов и зависимостей — проект работает офлайн.

## Локальный запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8765
```

и открыть `http://localhost:8765/`.
