# Спаси меня

Маленькая браузерная история-игра: ночная поляна, квест от Люми, платформер, бой с Сомнением и тёплый финал.

## Играть

https://kokaomefedron.github.io/spasi-menya/

## Управление

- `←` `→` или `A` `D` — идти
- `↑`, `W` или `Space` — прыгать
- `Space` или клик — листать диалоги
- На телефоне — экранные кнопки

## Персонализация

Имя в финале задаётся в самом верху `js/core.js`:

```js
const HER_NAME = 'Любимая';
```

## Технологии

Чистый HTML, CSS и JavaScript. Графика рисуется на Canvas 2D, музыка и звуки генерируются через WebAudio. Без внешних картинок, шрифтов и зависимостей — проект работает офлайн.

## Локальный запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8765
```

и открыть `http://localhost:8765/`.
